# 📊 Interactive Sales Analytics Dashboard

An interactive dashboard built using **Python, Pandas, Plotly Express, and Dash** to analyse sales performance.

## Features

- Filter sales data by city using an interactive dropdown
- Visualize revenue by product using a bar chart
- Analyze category-wise sales distribution using a pie chart
- Compare revenue generated by each salesperson
- Perform revenue calculations and data preprocessing using Pandas
- Build an interactive web dashboard using Dash and Plotly Express

## Technologies Used

- Python
- Pandas
- Plotly Express
- Dash
- Excel

## Dataset

The dashboard uses an Excel dataset containing:

- City
- Category
- Item
- Salesperson
- Price
- Discount
- Sold Unit

## Run the Project

Install dependencies:

```bash
pip install pandas plotly dash openpyxl
```

Run:

```bash
python app.py
```

Open:

```
http://127.0.0.1:8050/
```
